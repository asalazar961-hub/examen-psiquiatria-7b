# Primer Examen Parcial · Psiquiatría (M-0740) · 7.º "B"

Aplicación de examen individual, temporizado y anti-copia para el Primer Examen
Parcial de Psiquiatría (Temas 1 a 3), Universidad Tominaga Nakamoto, ciclo 2027-1.

- **Enlace del examen:** https://asalazar961-hub.github.io/examen-psiquiatria-7b/
- **Fecha:** jueves 17 de septiembre de 2026, 14:00-15:00 h (hora de Ciudad de México).
- **Formato:** 20 reactivos (opción múltiple y casos clínicos), 5 opciones cada uno.
  Cada alumno recibe una selección y un orden distintos.
- **Resultados:** calificación inmediata al enviar; el detalle de cada pregunta con
  la explicación llega por correo 30 minutos después del cierre.

Este repositorio solo contiene el front-end (index.html). El banco de
reactivos, la clave de respuestas y la lista de alumnos viven exclusivamente en
el backend privado de Google Apps Script, nunca en este repositorio público.
